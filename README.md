# 🟦⬛⬜ Jazia ABDELKRIM – Portfolio

> ### **Builds Ethical AI, Designs User-Centered UI!**
> **AI Modeling** ✦ **AI Ethics** ✦ **User Experience**

Personal portfolio of **Jazia ABDELKRIM**, AI engineering student and UX/UI designer. It presents my experience, projects, values and contact links in a single page, built with plain HTML, CSS and JavaScript (no frameworks, no build step).

**Live site:** https://jazia-abdelkrim.github.io/Portfolio/
**Github repository:** https://github.com/jazia-abdelkrim/Portfolio.git

---

## 🟦 Sections

* **About:** hero with name, headline and focus areas, followed by a "Trusted by" logo ribbon
* **Experience:** internship, freelance work and studies
* **Projects:** photo, title, date and description for each project
* **Values:** what guides the way I build and design
* **Contact:** email, LinkedIn and GitHub

---

## ⬛ Features

* Sticky header that highlights the current section in blue as you scroll, plus a scroll-progress line
* "Trusted by" ribbon with bigger logos in their real colors that loops infinitely to the right and pauses on hover
* Hero entrance animation and an animated gradient and light sweep on the name box
* Cards and section titles that reveal on scroll
* Card hover effects (hard blue shadow, rotating square, zooming project photo)
* Custom blue cursor and blue square favicon
* Responsive layout from phones to wide desktops
* Accessible by default: semantic HTML, keyboard focus styles, and `prefers-reduced-motion` support (animations are turned off and the ribbon becomes a static row)

---

## ⬜ Tech stack

* HTML5
* CSS3 (custom properties, grid, flexbox, container queries)
* Vanilla JavaScript (IntersectionObserver, requestAnimationFrame)
* Google Fonts: Encode Sans Expanded
* Abu Dhabi Pro (licensed font, self-hosted)
